# v0.9.1-windows-preview

**预发布，不是 Native 1.0。** 自签名 MSI，其他电脑仍可能 SmartScreen 警告。

相对 0.9.0：创建向导、删除环境关内核、搜索引擎用扩展覆盖、Win11 Client Hints、代理密码、QUIC/IPv4、上限弹窗。

## 本机打包

需要 Git、Node 22、Rust stable、VS Build Tools（C++）。先关掉正在运行的 Enclave。

```powershell
git clone git@github.com:liangwenli1/enclave.git
cd enclave
git checkout v0.9.1-windows-preview
powershell -ExecutionPolicy Bypass -File .\scripts\windows-msi.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\windows-selfsign.ps1
gh release upload v0.9.1-windows-preview ".\apps\desktop\src-tauri\target\release\bundle\msi\Enclave_0.9.1_x64_en-US.msi" --clobber
```

已有仓库时：

```powershell
git checkout -- src/routeTree.gen.ts apps/desktop/src-tauri/Cargo.toml
git pull
git checkout v0.9.1-windows-preview
powershell -ExecutionPolicy Bypass -File .\scripts\windows-msi.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\windows-selfsign.ps1
gh release upload v0.9.1-windows-preview ".\apps\desktop\src-tauri\target\release\bundle\msi\Enclave_0.9.1_x64_en-US.msi" --clobber
```
