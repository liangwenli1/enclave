# v0.9.0-windows-preview

**预发布，不是 Native 1.0。** 未签名，不是安装包。

Windows x64 已跑通：准入 fingerprint-chromium 148、磁盘哈希、本机 spawn、CDP 只绑 127.0.0.1、代理、实验室、工作台设置搜索引擎。

## 怎么用

需要 Git、Node 22、Rust stable、VS Build Tools（C++）。

```powershell
git clone git@github.com:liangwenli1/enclave.git
cd enclave
git checkout v0.9.0-windows-preview
powershell -ExecutionPolicy Bypass -File .\scripts\windows-dev.ps1
```

内核页准入 → 新建环境 → 启动。本机弹出独立 Chromium 窗口。

说明见 [docs/windows.md](../windows.md)。

## 不是这个版本的

- 签过名的 `.msi` / `.dmg`
- 双击安装、开始菜单图标
- 账号订阅后台
