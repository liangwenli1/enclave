# 威胁模型

实现按这张表挡发布。"已实现"必须能在验收清单里被验证。

| 编号 | 对手 | 第一版必须防 | 状态 |
|---|---|---|---|
| T1 | 恶意内核镜像 / 更新包被换 | 是：哈希不符拒启 | **已实现**：准入时记录可执行文件哈希，启动前核对 |
| T2 | 假安装包 | 是：1.0 必须签名 | **未实现**：证书未购买，当前靠下载页公示 SHA256 |
| T3 | 本机读配置库拿到密码 | 是：秘密进保险箱，不进明文 | **已实现**：PBKDF2 + AES-GCM，没设主密码就不保存 |
| T4 | 网页逃逸到 Host | 是：不关关键沙箱 | **已实现**：沙箱默认开，关闭需明确勾选并记审计 |
| T5 | 内核被降级到未准入版本 | 是：通道与哈希双重拦截 | **已实现**：`KERNEL_CHANNEL_BLOCKED` |
| T6 | 扫本机接口 / 网页驱动本机接口 | 是：仅回环、要令牌、限来源 | **已实现**：Host 头 + Origin 名单 + 32 字节 OsRng 令牌 |
| T7 | 环境之间串数据 | 是：独立 user-data | **已实现** |
| T8 | 工作台偷用户数据 | 是：无内容遥测 | **已实现**：只连本机服务与自己的许可证服务 |
| T9 | 代理密码进日志 | 是：密码不出保险箱 | **已实现**：日志和诊断包里只有地址，没有凭据 |
| T10 | 伪造许可证白嫖 | 是：签名验不过就回落免费档 | **已实现**：Ed25519，公钥内置，失败不"姑且相信" |
| T11 | 伪造的远程内核清单（中间人、被攻破的工作台页面、回放旧清单） | 是：清单决定本机下载并执行什么 | **已实现**：本机服务用内置公钥验 Ed25519 签名（带域前缀），地址限定上游 Release，拒收更旧的清单 |

## 明确不承诺

- 国家级完整控机。操作系统本身被入侵时，本机软件保护不了用户。
- 用户主动关掉的保护（沙箱、预览通道内核）造成的后果。
- 逆向本机客户端改额度。本地优先产品的固有边界；服务端只保证**没有厂商签名就
  拿不到高于免费档的许可证**。
- 延迟未公开补丁窗口内的未知逻辑漏洞。
- 任何网站的风控结果。

## 复核时机

每次改动 `crates/host/`、`apps/vendor/`、`src/lib/vault.ts`、`src/lib/license/`
都要回来看这张表还成不成立。
