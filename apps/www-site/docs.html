安装

打开官网下载页，核对本机系统对应安装包的 SHA256。哈希为空则不要装。安装后打开本机工作台并登录。内核不预置在安装包里：第一次启动前由内核管理器按清单下载并校验。

创建环境

工作台首页新建环境。来源可选空白、模板或复制。生成画像后锁定种子。档位上限在创建时强制：Free 3、Solo 50、Pro 200。超限只能升级。启动前内核必须已准入，否则原因码 KERNEL_UNTRUSTED_SOURCE。

代理

网络页添加 HTTP / HTTPS / SOCKS5。密码只存保险箱引用，不进配置明文、不进日志。环境绑定一个代理。工作台探测出口不等于内核出口。失败停在错误态，不显示 Running。

实验室

先启动环境。对照采集当前页，内核采集走 CDP。无显示器时内核 headless，文案标明 runtime: native。不把对照页冒充成内核窗口。

API

默认关闭。Free 不能开。开启后只监听本机回环并要求 token。不要把 Host 暴露到公网。

安全说明

启动前磁盘哈希必须匹配。调试口只绑 127.0.0.1。默认开沙箱；--no-sandbox 必须明确勾选并写入审计。不承诺过某站风控。披露邮箱 security@enclave.local（草稿）。
